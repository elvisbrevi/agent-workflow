# Require behavior-appropriate completion evidence

Every Azure delivery ticket must contain evidence appropriate to the implemented behavior before it reaches `Done`: Chrome MCP HTTP request and response captures for backend work, rendered-screen captures for frontend work, both for mixed work, and reproducible test or command output for changes without an executable interface. When the required application, environment, authentication, or Chrome capability is unavailable, the ticket remains blocked rather than substituting an unsupported textual claim.
