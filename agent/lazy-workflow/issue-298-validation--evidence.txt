Issue #298 -- Default --model per coding agent CLI (ADR-0034)

`--model` now defaults to a model resolved from a new AGENT_CLI_PROFILES table
keyed by --cli (agent/lazy-workflow/src/coding-agent/agent-cli.ts), instead of
one global `opencode-go/deepseek-v4-pro` constant that was silently wrong for
`claudecode`. `variantRejection`/`isValidVariant`
(agent/lazy-workflow/src/cli/parse-cli-options.ts) read the accepted effort
set from that same table instead of hard-coding `cli !== "claudecode"`. The
code-review pass on this change (Spec axis) found that recovery adopting a
different CLI than the one --cli/--model parsed against (no explicit
--model, no live session yet) kept the stale default instead of the adopted
CLI's own -- fixed in adoptCheckpointCli
(agent/lazy-workflow/src/cli/lazy-workflow-cli.ts), with a regression test.
